# riscv-disasm-trace

Учебный проект на C++20: декодер, дизассемблер и пошаговый эмулятор базовой архитектуры **RISC-V (RV32I)**.

Проект написан в рамках самостоятельного изучения низкоуровневого программирования и архитектуры процессоров. Реализован разбор машинных инструкций, выделение полей и знаковых смещений (immediates), работа с регистровым файлом и памятью, а также сбор статистики по выполненным инструкциям.

---

## Что реализовано

- **Декодирование и поддержка инструкций RV32I:**
  - **R-тип:** `ADD`, `SUB`, `SLL`, `SLT`, `SLTU`, `XOR`, `SRL`, `SRA`, `OR`, `AND`
  - **I-тип:** `ADDI`, `SLTI`, `SLTIU`, `XORI`, `ORI`, `ANDI`, `SLLI`, `SRLI`, `SRAI`, `LW`, `JALR`
  - **S-тип:** `SW`
  - **B-тип:** `BEQ`, `BNE`, `BLT`, `BGE`, `BLTU`, `BGEU`
  - **U-тип:** `LUI`, `AUIPC`
  - **J-тип:** `JAL`
- **Дизассемблер:** преобразование машинного кода в читаемый ассемблер (с поддержкой как стандартных номеров регистров `x0-x31`, так и ABI-имен `zero`, `ra`, `sp`, `a0-a7` и др.).
- **Эмулятор процессора:**
  - 32 целочисленных регистра (с соблюдением правила `x0 == 0`).
  - Регистр счетчика команд (PC).
  - Память 64 КБ (Little Endian).
  - Сбор статистики по категориям (ALU, ветвления, переходы, память).
- **Тесты:** 25 модульных тестов на Google Test, проверяющих разбор команд, расширение знака, циклы, работу с памятью и вычисление чисел Фибоначчи.

## Сборка и запуск

Для сборки требуется компилятор с поддержкой C++20 (GCC 11+, Clang 13+, MSVC 2019+) и CMake версии 3.20 или выше. Google Test подтягивается автоматически через CMake (FetchContent).

### Сборка

```bash
# Конфигурация
cmake -B build -DCMAKE_BUILD_TYPE=Release

# Компиляция
cmake --build build --config Release
```

### Запуск тестов

```bash
ctest --test-dir build -C Release --output-on-failure
```

### Запуск примера

В `examples/main.cpp` находится тестовая программа на ассемблере RV32I, вычисляющая 10-е число Фибоначчи (`fib(10) = 55`):

```bash
# Linux / macOS
./build/examples/riscv_demo

# Windows
./build/examples/Release/riscv_demo.exe
```
