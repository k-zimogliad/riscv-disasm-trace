# riscv-disasm-trace

Небольшой дизассемблер и эмулятор набора инструкций RV32I на C++20. Читает машинный код, показывает его в виде ассемблера и умеет выполнять шаг за шагом, считая, какие инструкции сколько раз сработали.

## Что умеет

- декодировать все базовые инструкции RV32I (арифметика, загрузка и сохранение, ветвления, `LUI`/`AUIPC`, `JAL`/`JALR`, `ECALL`, `EBREAK`, `FENCE`);
- печатать их как ассемблер, с именами регистров `x0..x31` или ABI-именами (`zero`, `ra`, `sp`, `a0`...);
- пошагово трассировать исполнение (`EnableTracing`, колбэки) с выводом текущего PC, ассемблера и изменений регистров;
- выполнять программу: 32 регистра (`x0` всегда равен нулю), память little-endian, отслеживание выхода за границы (`HasMemoryFault`), остановка по `EBREAK`/`ECALL`;
- загружать программы как из массивов машинных слов, так и из сырых бинарных файлов `.bin` (`LoadBinary`);
- выводить статистику: сколько было арифметических команд, ветвлений, переходов, обращений к памяти и системных вызовов.

Тесты написаны на Google Test, их 37 штук: проверка опкодов и funct-полей, знаковое расширение, границы памяти, трассировка, загрузка бинарников и запуск программ.

## Структура

```
include/riscv/    заголовки: типы, инструкция, декодер, дизассемблер, эмулятор
src/              реализация
examples/main.cpp демо: считает fib(10)
tests/            тесты декодера и эмулятора
```

## Сборка

Нужны компилятор с C++20 (GCC 11+, Clang 13+, MSVC 2019+) и CMake 3.20+. Google Test скачивается сам через `FetchContent`.

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release
```

Тесты:

```bash
ctest --test-dir build -C Release --output-on-failure
```

Демо:

```bash
./build/examples/riscv_demo                    # Linux / macOS
./build/examples/Release/riscv_demo.exe        # Windows
```

## Пример

Демо дизассемблирует программу, считающую числа Фибоначчи, и запускает её:

```
0x0000  0x00a00513  addi a0, zero, 10
0x0004  0x00000593  addi a1, zero, 0
0x0008  0x00100613  addi a2, zero, 1
...
0x0028  0x00100073  ebreak

fib(10) в регистре a1: 55
```

После запуска печатаются дамп регистров и статистика по категориям команд.
